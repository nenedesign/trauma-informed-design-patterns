# Calm Visual Tone

## Problem

Aggressive color palettes, flashing elements, or sudden motion increase cognitive and emotional load in high-stress review environments. Users who are already processing distressing content do not need the interface adding to that load through visual design choices that signal urgency or alarm.

## Design Guidance

Use a calm, neutral color palette. Reserve red for critical errors and irreversible actions only. Use amber or yellow for warnings. Avoid applying high-contrast alert colors to routine UI elements.

No auto-play media. No flashing or animated elements in standard states. Motion should be purposeful and minimal; if an animation does not communicate something, remove it. Provide a reduced-motion option that respects system-level accessibility settings.

Dark mode should be available by default, not buried in settings. Evidence review environments are often used for extended sessions; dark mode reduces eye strain and lowers the visual intensity of the interface.

## Do

- Neutral color palette (grays, muted blues, low-saturation tones) for the primary UI
- Red used only for: permanent deletions, errors that require immediate action, and critical system failures
- Reduced-motion option accessible from the workspace, not only from account settings
- Dark mode available on first use, not after onboarding

## Don't

- Red badges or indicators on routine notification types
- Auto-play video or audio on asset load or hover
- High-contrast animated transitions between evidence items
- Flashing or pulsing indicators for non-critical states

## Risk Level

**Medium** - Failure increases cognitive and emotional load; does not directly cause re-traumatization but compounds it.
