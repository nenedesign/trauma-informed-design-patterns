# Annotation and Distance

## Problem

Raw, unstructured evidence review without tools for analysis encourages passive scrolling and increases exposure without productive output. Investigators process more distressing content than necessary when there is no mechanism to record findings, mark progress, or create analytic separation between themselves and the material. The absence of structure collapses the distance between the reviewer and the content.

## Design Guidance

Provide annotation tools that create analytic distance: notes, highlights, timelines, and structured forms. These tools shift the user from passive viewer to active analyst.

Allow items to be marked with defined statuses: "Reviewed," "Flagged," "Needs legal review," "Needs support." Tags should have clear, defined semantics; avoid open-ended tagging systems where the meaning of a tag depends on team convention that is never documented.

Annotation should be role-aware. Notes left by an examiner should be distinguishable from notes left by an investigator or a legal reviewer. All annotations should be time-stamped and attributed.

## Do

- "Mark as reviewed" closes the artifact and advances to the next item in the queue
- Timeline view available for communication artifacts (messages, calls, emails)
- Structured flag types with defined meanings: "Relevant," "Sensitive," "Needs legal review," "Needs support"
- Annotation panel docked alongside the artifact view, not in a separate screen
- All annotations attributed: "Added by M. Okoro (Examiner) 2026-01-15 14:32 UTC"

## Don't

- Flag options with no documented meaning (open tagging with no taxonomy)
- No way to mark progress on reviewed items in a long evidence set
- Annotation stored separately from the artifact record, requiring cross-reference
- A single note field shared across all roles with no attribution

## Risk Level

**High** - Failure increases unstructured exposure to distressing content and removes the cognitive distance that makes sustained review possible.

## Principles

- Empowerment, Voice, and Choice
- Collaboration and Mutuality
